Pharmacovigilance Case Analysis Dashboard

Project Overview

An interactive Power BI dashboard designed to analyze pharmacovigilance case data, including case outcomes, adverse events, drug distribution, seriousness, and processing time.

Tools Used

- Microsoft Power BI
- Microsoft Excel
- DAX 

Dashboard Preview
The dashboard preview will be displayed here.

"Pharmacovigilance Dashboard" (dashboard.png)

Key Analysis

- Total number of cases
- Average processing days
- Serious vs. non-serious cases
- Expected vs. unexpected cases
- Adverse event distribution
- Country-wise and drug-wise case analysis
